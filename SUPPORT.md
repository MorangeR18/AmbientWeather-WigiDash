# Support

## Setup questions and ideas

Use [GitHub Discussions](https://github.com/MorangeR18/AmbientWeather-WigiDash/discussions) for installation help, station-model questions, ideas, and examples of your dashboard. Search existing discussions first.

## Reproducible bugs

Use the structured [bug-report form](https://github.com/MorangeR18/AmbientWeather-WigiDash/issues/new?template=bug_report.yml). Include the widget version, WigiDash Manager version, Windows version, layout size, expected result, actual result, and reproducible steps.

## Security or sensitive information

Read [SECURITY.md](SECURITY.md). Never post API keys, Application Keys, exact station identifiers, MAC addresses, precise locations, or unredacted logs in Issues or Discussions.

## Not supported here

This project cannot provide support for AmbientWeather.net accounts, station hardware, WigiDash hardware, or WigiDash Manager itself. Use the respective publisher's official support channel for those products.
